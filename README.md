# Linux System Health Monitor


A simple Bash-based to monitor Linux system health

## Features

- Display system hostname and current user
- Shows current date and system uptime
- Monitor CPU and memory usages
- Check disk usage
- Generate health check reports
- Displays warnings when resourse usage is high

## Technologies Used

- Linux
- Bash Scripting
- Git
- GitHub

## Project Structure

- 'scripts/' - Health monitoring scripts
- 'logs/' - Generated log files
- 'reports' - Project reports

## How to Run
1. Clone this repository
2. Navigate to the project directory.
3. Run the following command:

     'bash scripts/health_check.sh'
